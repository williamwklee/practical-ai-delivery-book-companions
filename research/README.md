Use the report to learn how to keep a research question small, distinguish an observation from an inference, retain conflicting or qualifying evidence, and check both facts and arithmetic. The rainfall inputs are invented; no real local climate result or forecast is delivered.

## Reproduce the output-specific check

Download/extract the complete example bundle into a new exercise folder. On a computer with Python3.9 or later, open a terminal in that folder and run once:

    python3 check_arithmetic.py

It reads source-pack.json and prints20mm extra,25percent above and125percent of the assumed baseline. This is an arithmetic check, not a climate-trend or attribution test. The report and source notes identify what further evidence would be needed. If using a calculator instead, subtract80from100, divide20by80, and multiply by100.
