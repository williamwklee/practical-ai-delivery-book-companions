# Practical Work Delivery companion files

This repository contains the exercise files for *Practical Work Delivery with Multiple AIs* and its translated editions. The same files serve every language edition; translations can link to this release without copying the exercises. The book's PDF and EPUB are distributed through [Leanpub](https://leanpub.com/practical-work-delivery-with-multiple-ais).

**Download:** [Companion files v1.0.0 (ZIP)](https://github.com/williamwklee/practical-ai-delivery-book-companions/releases/download/v1.0.0/practical-work-delivery-companions-v1.0.0.zip). Extract the ZIP, keep its folder structure, and read [START-HERE.txt](START-HERE.txt). No GitHub account or paid Reader Membership is needed to download these files.

The repository includes editable diagrams and images, fictional research inputs, an editable presentation and renderings, example Python programs and tests, and a `COMPANION-MANIFEST.json` with file sizes and SHA-256 hashes. The examples are instructional. Some use consumer AI command-line tools or shared services and require the setup and finite-allowance steps in the book; the local research and calculator checks do not call an AI.

Private Jira and Confluence records are not distributed here. Some example notes retain links to the publisher's private historical archive for provenance; readers do not need access to those links to use the public files.
